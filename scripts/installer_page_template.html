Step 2 — Run it

Move it to your Downloads folder, then paste this into Terminal:

chmod +x ~/Downloads/__NAME__ && ~/Downloads/__NAME__
First run takes a few minutes. It compiles the entire engine from source so you get a real optimised arm64 build, not a generic download. Later runs are faster.

What it does

  • Checks you're on Apple Silicon and macOS 12+, and stops with a clear message if not
  • Installs Xcode Command Line Tools automatically if missing
  • Downloads CMake only if you don't already have it — no Homebrew needed
  • Builds Release, arm64
  • Verifies the build by running the game's own test suite on your machine before installing
  • Installs Haven.app and adds a haven command
Safe to re-run. Running it again rebuilds and updates in place. Your saves live in ~/Library/Application Support/Haven and are never touched.

Requirements

✓Apple Silicon (M1 or newer)
✓macOS 12 Monterey or newer
✓~1 GB free disk space
✓Internet (only if CMake is missing)

No Xcode, Homebrew, Python or Node required. Intel Macs are not supported — there is no Intel build.

All artwork, geometry and audio are original or generated at runtime. Nothing is copied from any existing game.
